1. PREREQUISITES

2. INSTALLATION STEPS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Extract the Project
───────────────────────────────────────────────────────────────────────────────
Extract the "engineer-portfolio" folder to your desired location.

Example locations:
  Windows: C:\Users\YourName\Projects\engineer-portfolio
  Mac/Linux: ~/Projects/engineer-portfolio


STEP 2: Open Terminal/Command Prompt
───────────────────────────────────────────────────────────────────────────────
Navigate to the project directory:

  cd path/to/engineer-portfolio

Example:
  Windows: cd C:\Users\YourName\Projects\engineer-portfolio
  Mac/Linux: cd ~/Projects/engineer-portfolio


STEP 3: Install Dependencies
───────────────────────────────────────────────────────────────────────────────
Run the following command to install all required packages:

  npm install

This will install:
  - React 18.3.1
  - React DOM 18.3.1
  - Vite 5.4.11
  - Lucide React (icons)
  - React Icons

Wait for the installation to complete (usually 1-3 minutes).

3. RUNNING THE APPLICATION
═══════════════════════════════════════════════════════════════════════════════

DEVELOPMENT MODE
───────────────────────────────────────────────────────────────────────────────
Start the development server:

  npm run dev

The application will:
  ✓ Start on http://localhost:3000
  ✓ Automatically open in your default browser
  ✓ Auto-reload when you make changes

To stop the server:
  Press Ctrl + C in the terminal

5. BUILDING FOR PRODUCTION
═══════════════════════════════════════════════════════════════════════════════

CREATE PRODUCTION BUILD
───────────────────────────────────────────────────────────────────────────────
Run the build command:

  npm run build

This creates an optimized production build in the "dist" folder.

The build will:
  ✓ Minify JavaScript and CSS
  ✓ Optimize images and assets
  ✓ Generate production-ready files


PREVIEW PRODUCTION BUILD
───────────────────────────────────────────────────────────────────────────────
Test the production build locally:

  npm run preview

Opens the production build at http://localhost:4173

6. DEPLOYMENT OPTIONS
═══════════════════════════════════════════════════════════════════════════════

OPTION 1: VERCEL (RECOMMENDED - EASIEST)
───────────────────────────────────────────────────────────────────────────────
1. Create a GitHub account (if you don't have one)
2. Push your code to GitHub:
   
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/yourusername/your-repo.git
   git push -u origin main

3. Go to https://vercel.com
4. Sign in with GitHub
5. Click "New Project"
6. Import your repository
7. Click "Deploy"

Your site will be live in 1-2 minutes!


OPTION 2: NETLIFY
───────────────────────────────────────────────────────────────────────────────
1. Push code to GitHub (same as Vercel steps 1-2)
2. Go to https://netlify.com
3. Sign in with GitHub
4. Click "Add new site" → "Import an existing project"
5. Select your repository
6. Click "Deploy site"


OPTION 3: GITHUB PAGES
───────────────────────────────────────────────────────────────────────────────
1. Install gh-pages:
   
   npm install gh-pages --save-dev

2. Add to package.json (in "scripts" section):
   
   "homepage": "https://yourusername.github.io/your-repo-name",
   "predeploy": "npm run build",
   "deploy": "gh-pages -d dist"

3. Deploy:
   
   npm run deploy

4. Enable GitHub Pages in repository settings

7. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "npm: command not found"
───────────────────────────────────────────────────────────────────────────────
SOLUTION: Install Node.js from https://nodejs.org/


PROBLEM: Port 3000 already in use
───────────────────────────────────────────────────────────────────────────────
SOLUTION: Edit vite.config.js, change port to 3001:

  server: {
    port: 3001,
    open: true
  }


PROBLEM: "Module not found" errors
───────────────────────────────────────────────────────────────────────────────
SOLUTION: Delete node_modules and reinstall:

  rm -rf node_modules package-lock.json
  npm install


PROBLEM: Changes not showing up
───────────────────────────────────────────────────────────────────────────────
SOLUTION: 
  1. Save the file (Ctrl+S / Cmd+S)
  2. Check browser console for errors (F12)
  3. Hard refresh browser (Ctrl+Shift+R / Cmd+Shift+R)
  4. Restart dev server (Ctrl+C, then npm run dev)


PROBLEM: Build fails
───────────────────────────────────────────────────────────────────────────────
SOLUTION: Check Node.js version:

  node --version

Should be v18 or higher. If not, update Node.js.
